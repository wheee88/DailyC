# 리눅스 운영 학습 가이드

이 디렉토리는 리눅스 운영체제를 체계적으로 학습하기 위한 실습 자료들을 포함합니다.

## 학습 순서

### 1. 기본 명령어 (basic-commands/)
- 파일과 디렉토리 조작
- 텍스트 파일 처리
- 시스템 정보 확인

### 2. 파일 시스템 관리 (file-system/)
- 파일 시스템 구조 이해
- 마운트/언마운트
- 디스크 사용량 관리

### 3. 프로세스 관리 (process-management/)
- 프로세스 모니터링
- 프로세스 제어
- 백그라운드 작업

### 4. 권한 관리 (permissions/)
- 파일 권한 이해
- 사용자/그룹 관리
- sudo 사용법

### 5. 쉘 스크립팅 (shell-scripting/)
- bash 스크립트 기초
- 변수와 조건문
- 반복문과 함수

### 6. 네트워크 (network/)
- 네트워크 설정
- 포트 관리
- 방화벽 설정

### 7. 서비스 관리 (services/)
- systemd 서비스
- 로그 관리
- 자동 시작 설정

### 8. 로그 관리 (logs/)
- 시스템 로그 분석
- 로그 로테이션
- 모니터링

## 실습 방법

각 디렉토리에는 실습 파일과 설명이 포함되어 있습니다.
터미널에서 직접 명령어를 실행해보면서 학습하세요.

```bash
# 예시: 기본 명령어 실습
cd linux-learning/basic-commands
cat 01-file-operations.md
```
