# DailyC

일상에서 바로 쓸 수 있는 작고 가벼운 C 프로그램 모음입니다.

## 프로그램

### `unit_converter.c`

길이, 무게, 온도를 한 번에 변환합니다. 길이는 mm·cm·m·km·in·ft, 무게는
mg·g·kg·lb·oz, 온도는 섭씨와 화씨를 지원하며 단위는 대소문자를 구분하지
않습니다.

```text
분야 선택: 3
변환할 값: 32
현재 단위: F
변환할 단위: C
변환 결과: 0.0000 c
```

### `budget_calculator.c`

수입과 최대 20개 지출 항목을 입력해 총지출, 잔액, 저축률을 계산합니다.
지출이 수입보다 많으면 잔액 대신 예산 초과액과 초과율을 표시하며, 지출이
없는 달도 입력할 수 있습니다.

```text
총 수입(원): 3000000
지출 항목 수(0~20): 3

지출 1 이름: 주거비
금액(원): 1200000
지출 2 이름: 식비
금액(원): 450000
지출 3 이름: 교통비
금액(원): 200000

[계산 결과]
총 수입: 3000000원
총 지출: 1850000원
잔액: 1150000원
저축률: 38.33%
```

### `recipe_scaler.c`

기존 레시피와 만들 인분의 비율에 맞춰 최대 20가지 재료의 양을 한 번에
조절합니다. 소수 인분과 수량, 공백이 포함된 재료명, g·ml·개 등 자유로운
단위를 사용할 수 있습니다.

```text
기존 레시피 인분: 2
만들 인분: 5
재료 수(1~20): 2

재료 1 이름: 쌀
기존 수량: 300
단위(예: g, ml, 개): g

재료 2 이름: 양념 물
기존 수량: 200
단위(예: g, ml, 개): ml

[조절 결과]
배율: 2.50배
쌀: 750.00 g
양념 물: 500.00 ml
```

### `date_difference_calculator.c`

두 날짜를 `YYYY-MM-DD` 형식으로 입력하면 날짜 차이와 앞뒤 방향을 계산합니다.
시작일과 종료일을 모두 포함한 기간도 함께 표시하며 윤년과 월별 일수를
검증합니다.

```text
시작 날짜: 2024-02-28
종료 날짜: 2024-03-01

[계산 결과]
두 날짜의 차이: 2일
시작일과 종료일을 모두 포함한 기간: 3일
종료 날짜가 시작 날짜보다 2일 뒤입니다.
```

### `discount_calculator.c`

상품의 개당 가격, 할인율, 구매 수량을 입력하면 할인 전 총액, 총 할인액,
할인 후 개당 가격과 최종 결제액을 계산합니다. 0%와 100% 할인 및 소수
할인율도 사용할 수 있습니다.

```text
상품 1개 가격(원): 20000
할인율(0~100%): 15
구매 수량: 5

[계산 결과]
할인 전 총액: 100000원
총 할인 금액: 15000원
할인 후 개당 가격: 17000원
최종 결제 금액: 85000원
표시 금액은 1원 단위로 반올림한 예상값입니다.
```

### `trip_fuel_calculator.c`

총 이동 거리, 차량 연비, 리터당 연료 가격을 입력하면 필요한 연료와 예상
연료비를 계산합니다. 동승자가 있다면 1인당 나눌 비용도 함께 보여 줍니다.

```text
총 이동 거리(km): 300
차량 평균 연비(km/L): 15
연료 가격(원/L): 1700
비용을 나눌 인원: 4

[예상 결과]
필요 연료: 20.00L
총 예상 연료비: 34000원
1인당 예상 비용: 8500원
실제 연비와 교통 상황에 따라 비용이 달라질 수 있습니다.
```

### `unit_price_comparator.c`

가격과 용량이 다른 두 상품의 단위가격을 계산해 어느 쪽이 얼마나 저렴한지
비교합니다. 두 상품의 용량 단위만 같게 입력하면 g, ml, 개 등 어떤 단위에도
사용할 수 있습니다.

```text
상품 A 가격(원): 10000
상품 A 용량: 1000
상품 B 가격(원): 7800
상품 B 용량: 600

[비교 결과]
상품 A 단위가격: 10.00원
상품 B 단위가격: 13.00원
상품 A가 단위가격 기준 23.08% 저렴합니다.
```

### `split_bill_calculator.c`

여러 사람이 결제 금액을 나눌 때 송금하기 편한 단위로 정산합니다. 총무를
제외한 사람들의 송금액을 지정한 단위로 내리고, 남은 금액은 총무 부담액에
합쳐서 전체 합계가 정확히 맞도록 계산합니다.

```text
총 결제 금액(원): 57300
정산 인원(총무 포함): 4
송금 단위(예: 1, 10, 100, 1000): 100

[정산 결과]
총무 외 3명 송금액: 14,300원
총무 최종 부담액: 14,400원
총무가 다른 사람보다 100원 더 부담합니다.
```

### `time_calculator_v2.c`

두 시각의 차이를 계산하거나 기준 시각에 원하는 기간을 더하고 뺍니다. 자정을
넘는 계산과 24시간보다 긴 기간을 지원하며 macOS, Linux, Windows에서 C11
컴파일러로 빌드할 수 있습니다. `time_calculator.c`는 최초 Windows 전용
버전으로 보관하고 있습니다.

```text
번호 입력: 2
기준 시간(시 분): 23 30
기간(시 분): 26 45
더한 결과: 02:15
```

## 빌드와 실행

새로 추가되는 프로그램은 C11을 지원하는 컴파일러로 함께 빌드할 수 있습니다.

```sh
make
./split_bill_calculator
./unit_price_comparator
./trip_fuel_calculator
./discount_calculator
./date_difference_calculator
./time_calculator_v2
./recipe_scaler
./budget_calculator
./unit_converter
```

테스트와 빌드 결과 정리는 다음 명령으로 실행합니다.

```sh
make test
make clean
```
